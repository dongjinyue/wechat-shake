## 在手机上测试

1. 在已取得最高权限的手机上准备兼容当前系统、支持传统 Xposed 模块接口的框架，例如 LSPosed。不同最高权限管理器的框架安装方式各异。
2. 安装本 APK（安卓安装包），在框架管理器的「模块」中启用「摇动助手」，作用域选「微信」。彻底关闭微信再打开，让新进程加载模块。如果活动通过一次性二维码进入，先保存能重新进入的方式。
3. 打开「摇动助手」，授予悬浮窗权限。「快速变向」默认开启，每次正负峰切换约 20 毫秒，高频时按半个周期缩短；关闭后采用原来的平滑正弦波。首次测试选每秒 2 次、时长 5 秒，点「打开悬浮控制」。可拖动面板上方文字移动位置。悬浮背景为 50% 透明，两个输入项上下排列。直接点面板上的「次数/秒」或「时长（秒）」输入数字，再点「开始」应用；运行中编辑的数值用于下一轮。
4. 用微信进入活动，在有效计数时间先验证手摇能增加次数。记下静止时的初值，保持手机静止，点悬浮窗「开始」立即启动并计时。可随时点「停止」，到时自动结束。再次测试时同时记录页面初值与末值。
5. 点「关闭」退出悬浮控制。可再次手摇确认页面能识别真实输入。如需彻底停用，在框架里禁用模块并重启微信。

## 如何读状态

| 悬浮窗提示 | 含义 |
|---|---|
| 未收到微信模块回执 | 检查框架是否已启用、作用域是否勾选微信，以及微信是否已重启。 |
| 当前系统适配失败 | 微信端加载了模块，但当前系统的传感器分发接口与模块预期不一致。 |
| 模块在线，等待传感器 | 微信端已响应，暂时未观察到所支持的加速度事件。可确认活动是否已进入可摇动阶段。 |
| 采样不足，可降低频率 | 收到事件，但相邻样本间隔太长，波形不足以表达所选频率。 |
| 正在输出 | 微信的加速度分发路径已收到模拟值。页面如何解释这些值要在活动中观察。 |
| 已输出次数 | 实际采样覆盖的完整来回数，多路同时订阅时取单路最大值。首次采样、末尾的不足一周期和断流可能让这个数低于「频率 × 时长」。 |

## 实现与验证

采用 Java（安卓开发语言）和传统 Xposed（应用运行时拦截框架）接口。核对的安卓分发入口见 [Android 13 系统传感器管理器源码](https://android.googlesource.com/platform/frameworks/base/+/refs/tags/android-13.0.0_r1/core/java/android/hardware/SystemSensorManager.java)。

- `WechatHook.java` 只针对微信各进程，在系统向监听器分发普通加速度或线性加速度时，复制本次数据并在 X、Y、Z 三轴分别叠加峰值为 18 米/秒² 的往返波形，保留原有重力、时间戳及精度。当前适配范围为安卓 Java 层的传感器分发。使用原生接口或其他数据源的页面仍需单独验证。
- `Motion.java` 按真实传感器事件时间计算波形与完整周期，相邻采样间隔必须短于半个周期。超长间隔终止当前残缺周期。
- `Panel.java` 从点击「开始」时计算截止时间。控制服务约每 180 毫秒发送定向广播；接收端逐次核对截止时间及 700 毫秒的有效期，失联后自动放行真实读数。启动时间晚于会话创建时间的微信进程忽略旧会话。
- `Controls.java` 提供参数设置和悬浮窗权限入口。作用域覆盖运行中的微信传感器监听器，无法仅按扫码网址筛选。
- 本地以 5 毫秒间隔覆盖平滑和快速模式每秒 1～50 次，并验证每秒 50 次会跳过间隔大于等于 10 毫秒的样本。另覆盖 1～10 次/秒分别按 5、10、20 毫秒间隔采样，校验完整周期、正反两个方向、参数边界和断流。构建还检查安装包签名、对齐和模块入口。小米 12 的活动页计数、端到端停止时间及各档可用频率仍待真机验证。

## 本地重新构建

在 Windows 下使用 Python 3.9 或以上版本，令 JAVA_HOME 指向完整 Java 8 开发工具包。首次从仓库下载源码时，请先按下文设置三个安卓构建依赖的路径，然后在本目录执行：

```powershell
python build.py
```

该命令先运行测试，再编译程序、打包、签名、验证，并更新 `build/wechat-shake-0.8.apk`。首次构建会在 build 下创建本地调试签名；保留该密钥可以覆盖安装后续版本。若迁移目录到另一台电脑，可提供 Android 30 的 android.jar、Windows Build Tools 30.0.3 和 Xposed API 82 的 jar，分别通过 ANDROID_JAR、ANDROID_BUILD_TOOLS 和 XPOSED_API 指定。接口库只参与编译，在手机上由框架提供。
